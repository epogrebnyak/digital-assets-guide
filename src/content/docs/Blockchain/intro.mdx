## What is blockchain?

Append-only, distributed ledger for data storage and program execution secured by cryptography and consensus of trustless participants.

Core operational concepts:

| Concept      | Description                                                                      |
| ------------ | -------------------------------------------------------------------------------- |
| Immutable    | Append-only database.                                                            |
| Distributed  | Data resides at several nodes.                                                   |
| Trustless    | Nodes reach consensus on true data while assuming any node may be untrustworthy. |
| Incentivized | Internal currency units are used to reward node operators.                       |
| Programmable | Can run small programs.                                                          |

## Why build it?

Several motivations shape blockchain development:

- censorship resistance – activity cannot be blocked by any central authority,
- self-custody – users retain control over their assets,
- universal access – anyone with an internet connection can participate,
- transparency and privacy.

> See ["Decoding Bitcoin: A Cypherpunk's Manifesto for Financial Freedom"](https://d-central.tech/decoding-bitcoin-a-cypherpunks-manifesto-for-financial-freedom/). During hype bubbles and Bitcoin price surges, the anarchist builder's idealism may turn into [cryptobro toxicity](https://www.reddit.com/r/Buttcoin/comments/1s30r3z/a_message_to_crypto_bros_who_might_be_reading_here/).

- Bitcoin (2008) and Ethereum (2015) launches.
- ICO (2017–2018) and NFT (2021–2022) bubbles.
- DeFi summer (2020) and L2 scaling (2021). {/* Arbitrum One launched August 2021, Optimism mainnet followed that December — this marked the shift from theoretical scaling to live rollups with real TVL */}

- Tokenization and institutional adoption (2026).
